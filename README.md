# 🚀 PHP CRUD Project

A simple and professional **Student Management System** built using PHP & MySQL.

---

## 🔥 Features

* ➕ Add User
* 📋 View Users
* ✏️ Update User
* ❌ Delete User

---

## 🛠️ Tech Stack

* PHP
* MySQL
* HTML
* CSS

---

## 📂 Project Setup

1. Clone repository
2. Move folder to:
   C:\xampp\htdocs\
3. Start Apache & MySQL (XAMPP)
4. Import database (crud_db)
5. Run:
   http://localhost/crud/
